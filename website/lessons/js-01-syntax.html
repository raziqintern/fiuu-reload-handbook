JavaScript Basics

Variables & Syntax

JavaScript is what runs inside the browser tab, separate from anything C# is doing on the server. Every "Try it Yourself" box on this site is itself a small JavaScript program — this is a good moment to actually understand how they work.

Declaring variables

Modern JavaScript has three ways to declare a variable. Use let by default, const when the value never gets reassigned, and avoid var (an older, quirkier version kept only for backwards compatibility).

let amount = 25.5;
const currency = "MYR";
let isConfirmed = false;

console.log(amount, currency, isConfirmed);

amount = amount + 10;
console.log("New amount:", amount);

The trap that catches everyone once JavaScript will happily let you add a number and a string — and it won't throw, it'll silently convert. 5 + "5" is "55" (a string), not 10. This "helpful" coercion is a real source of bugs when data arrives from a form field (always a string) and you forget to convert it with Number(...) first.

Try it yourself

Predict what each line logs before you hit Run.

let quantity = "5";   // came from a form field — always a string
let price = 10;

console.log(quantity + price);        // string concatenation, not addition
console.log(Number(quantity) + price); // now it's real addition

console.log(typeof quantity);
console.log(typeof price);
