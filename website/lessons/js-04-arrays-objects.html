Arrays & Objects

Every API response you'll ever inspect in the Network tab is one of these two shapes. Recognising them on sight is a real, daily-use skill.

Objects: key/value data

const terminal = {
  terminalId: "TNG-0042",
  merchantName: "7-Eleven KL",
  isOnline: true,
  lastAmount: 25.5
};

console.log(terminal.terminalId);
console.log(terminal["merchantName"]); // same as .merchantName, useful when the key is dynamic

terminal.lastAmount = 30.0; // objects are mutable after creation
console.log(terminal);

Arrays: ordered lists

const amounts = [10, 25.5, 100, 5];

console.log(amounts.length);
console.log(amounts[0]);       // first item, index 0
console.log(amounts[amounts.length - 1]); // last item

const total = amounts.reduce((sum, a) => sum + a, 0);
console.log("Total:", total);

const large = amounts.filter((a) => a > 20);
console.log("Over 20:", large);

.filter(), .map(), and .reduce() are the three you'll see constantly: filter keeps items matching a condition, map transforms every item into something else, reduce collapses the whole array into one value.

Arrays of objects — the shape of most real data

const transactions = [
  { transNo: "TXN-1001", amount: 10.0, status: "Success" },
  { transNo: "TXN-1002", amount: 25.5, status: "Pending" },
  { transNo: "TXN-1003", amount: 5.0, status: "Failed" }
];

const pending = transactions.filter((t) => t.status === "Pending");
console.log("Pending count:", pending.length);

const transNos = transactions.map((t) => t.transNo);
console.log(transNos);
This is what a JSON API response looks like When you inspect a Network request in DevTools and see a response body, it's almost always exactly this: an array of objects, or a single object. Reading it is the same skill as reading the code above.

Check your understanding

transactions.filter(t => t.status === "Pending") — what does this return?

  • The single pending transaction object.
  • A new array containing every transaction whose status is \"Pending\".
  • true or false, depending on whether any transaction is pending.
