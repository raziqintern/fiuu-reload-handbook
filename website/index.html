A W3Schools-style, learn-by-doing course for becoming a Fiuu reload software engineer — HTML, JavaScript, C#, VB.NET and SQL fundamentals, algorithms and language-agnostic design/best-practices, then the real conventions, architecture and debugging habits this specific codebase actually uses.

How this is different from a normal tutorial site

Most of the web teaches generic C# or generic SQL. The first few tracks here do that too — but the back half of this site is reverse-engineered from the real reload and reload_db codebases: real naming quirks, real layering patterns, real recurring bugs, real reviewer nitpicks. Where a lesson quotes code, it's a real snippet with a file:line citation, not an invented example.

Recommended path If you're new to programming, start at HTML Basics and go in order down the sidebar. If you already know C#, jump straight to Fiuu C# Conventions — that's the track that actually onboards you onto this codebase.

About the "Try it Yourself" boxes

Every language here gets a live editor, but "live" means different things depending on what can actually run in a browser with no backend server:

  • HTML — real, instant preview in an embedded frame.
  • JavaScript — real execution in a sandboxed frame; console.log output shown next to your code.
  • SQL — a real SQLite engine running in your browser via WebAssembly (sql.js), pre-seeded with a small practice schema shaped like reload_db.
  • C# and VB.NET — these need a real compiler, which means a hosted backend. This site has none (by design — no server to maintain, no API key to manage, works offline). Instead you get Predict → Reveal: read the code, guess the output, then reveal the verified real answer. Copy the code into Visual Studio, dotnet run, or an online compiler any time you want to actually run it.

From Algorithms & Data Structures onward, most examples carry a C# / VB.NET tab switcher right on the box — the same logic, shown in both of reload's real languages, so you can compare them side by side instead of guessing at the translation.
