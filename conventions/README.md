# Coding Conventions

Fiuu has no documented coding standard for this codebase (`CONTRIBUTING.md` in
class-library is generic GitLab boilerplate). Everything here is reverse-engineered
from the actual code, with real snippets as evidence — not idealized guidelines.

Planned docs: naming conventions, layering/module boundaries, error handling,
logging, DB access/transaction patterns, comment style, and how these differ
(if at all) between class-library, web_api, and the front-end apps.
